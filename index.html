Ready to book? Use our secure appointment request form to choose your hairstyle, length, braid size, shampoo option, preferred date and time, and deposit method.

How booking works

1. Submit your appointment request using the button below.

2. Crown Beauty Services reviews the requested style, price and availability.

3. You receive deposit instructions. A $25 deposit is required to secure the appointment.

4. Your booking is confirmed only after the deposit is verified and we approve your appointment.

Appointment requests are not guaranteed time slots. No payment is collected on this website.

Owner note — how to update published prices

To change the prices everyone sees, edit the defaults list in index.html on GitHub. Each entry is ['Hairstyle name', startingPrice, 'Description']. Change only the number, then commit the file. The live website will update after GitHub Pages republishes. This is not a private admin dashboard.
